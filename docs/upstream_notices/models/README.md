# Models

실제 전신 표면과 리그는 assets/fullbody/fullbody_muscles_skin.glb이며, 출처/수정사항은 assets/fullbody/CREDITS.md입니다.

mobl/은 이전 상지 모델 보관본으로 현재 기본 영상 계산에 사용하지 않습니다.
