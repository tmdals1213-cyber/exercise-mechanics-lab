# 현재 기준

현재 결과는 루트 README와 results/ohp_fullbody/fullbody_metadata.json을 기준으로 합니다. 이전 상지 두 축 분석과 경로 도식은 역사적 결과입니다.

현재 계산: 전신 MyoSim 역동역학, 양발의 8점 지지와 마찰 제약, 비음수 요구 장력, 자유 루트 보조력 0. 근육 표면은 실제 BodyParts3D 자료입니다. 명시적 대응이 없는 표면은 회색입니다. 개인별 최대 수행 능력, 동시수축, EMG, 피로·손상은 추정하지 않습니다.

검증: validation_fullbody.json과 rig_validation.json. 하단 384 px는 비웁니다.
